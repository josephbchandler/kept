# Kept

Kept is a small, curated index of well-made everyday objects (desk gear, carry, coffee, tech, home goods and books), each with a photo, a price and a short note on why it's worth owning. Browse by category or brand, or search by name. All data is bundled with the app; there is no database, no API and no environment variables.

## Run it

Requires Node 20+ (22 recommended, see `.nvmrc`).

```bash
npm install
npm run dev        # http://localhost:3000
```

Production build: `npm run build && npm start`.

Checks: `npm run lint`, `npm run typecheck`, `npm test`.
